BedrockTool: Minecraft Bedrock World Downloader

Most of the worlds and packs in this archive were saved with BedrockTool, a free and open-source Minecraft Bedrock server downloader. It sits between your game and a server and saves what the server sends you: the world, its resource packs and player skins.

Download BedrockTool View on GitHub

What it can download

  • Worlds: saves Bedrock server and Realm worlds as a .mcworld you can open in single player, including entities, maps and the chests you open.
  • Resource packs: a Minecraft server pack downloader that keeps every pack a server sends.
  • Skins: saves the skins of players on the server.
  • Menus and scoreboards: can record a server's menus into the saved world so they still open offline.
  • Recordings: records a session to a file and replays it later, so a world can be saved again with different settings without rejoining.

How to download servers on Minecraft Bedrock

  1. Download BedrockTool from the releases page and open it.
  2. Pick Worlds (or Packs for resource packs), then type a server address or choose a Realm or featured server.
  3. Press Start and sign in with your Microsoft account the first time.
  4. In Minecraft, go to Servers → Add Server and add 127.0.0.1, port 19132. Join it.
  5. Play as usual and walk around to load the areas you want to keep.
  6. Disconnect. Your world is saved as a .mcworld, ready to import.

The BedrockTool README covers every option, including the command line version.
